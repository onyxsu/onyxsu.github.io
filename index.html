Installation Guide

Method 1 — Custom Recovery
  1. Download latest kernel ZIP.
  2. Boot into custom recovery.
  3. Select Install and flash ZIP.
  4. Reboot system.
Method 2 — Fastboot Direct Flash
fastboot flash boot boot.img
fastboot reboot
Method 3 — A/B Partition Flash (If direct flash fails)

Some devices may require flashing the active slot manually.

fastboot flash boot_a boot.img
fastboot flash boot_b boot.img
fastboot reboot

Use this method if normal fastboot flash boot does not work or boot image is not detected correctly.
